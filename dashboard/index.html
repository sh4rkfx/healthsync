Erholung

HRV über Nacht

Die Herzfrequenzvariabilität misst, wie stark der Abstand zwischen zwei Herzschlägen im Schlaf schwankt. Liegt das 7-Tage-Mittel mehrere Tage unter deinem Normalbereich, sind Belastung, wenig Schlaf, Alkohol oder ein Infekt die üblichen Gründe. Eine einzelne niedrige Nacht sagt wenig.

Schlaf

Schlafenszeiten

Jeder Balken ist eine Nacht vom Einschlafen bis zum Aufwachen, der Abend oben, der Morgen unten. Garmin überschätzt die Schlafdauer im Mittel um etwa eine halbe bis drei viertel Stunde; die Zeiten selbst sind brauchbar.

Quelle: garmin_daily.csv · sleep_start_local, sleep_end_local

Nacht vor einem WerktagFreitag- und Samstagnacht

Werktage und Wochenende

Werktage sind die Nächte von Sonntag bis Donnerstag, Wochenende die Freitag- und Samstagnacht. Die Schlafmitte liegt zwischen Einschlafen und Aufwachen; wie weit sie sich am Wochenende verschiebt, heißt sozialer Jetlag. Ab etwa einer Stunde bringen Studien ihn mit schlechterem Schlaf in Verbindung.

Späte Nächte und HRV

Jeder Punkt ist eine Nacht: waagrecht die Einschlafzeit, senkrecht die HRV dieser Nacht im Vergleich zum 7-Tage-Mittel bis zum Vortag. Die Trendlinie nutzt nur Nächte mit Sleep Score ab 80, damit kurze oder gestörte Nächte die Steigung nicht bestimmen.

Kraft

Geschätztes 1RM der Hauptübungen

Bester Arbeitssatz jeder Einheit, umgerechnet auf eine Wiederholung

Epley-Formel: Last × (1 + Wiederholungen / 30), aus Sätzen mit bis zu 10 Wiederholungen, ohne Aufwärmsätze. Bei Klimmzügen und Dips zählt das Körpergewicht mit. Welche Übungen hier stehen, wählst du über „Übungen wählen“. Ohne eigene Auswahl gilt MAIN_LIFTS oben im Skript, und ohne Treffer dort erscheinen die vier häufigsten.

Quelle: hevy_sets.csv · weight_kg, reps, set_type · Körpergewicht aus garmin_daily.csv

Bis zu sechs Übungen. Die Auswahl gilt sofort und bleibt in diesem Browser gespeichert; die Diagramme folgen der Reihenfolge deiner Klicks. Übungen ohne Sätze bis 10 Wiederholungen lassen kein e1RM zu und sind gesperrt.

Zusammenhänge

      

    

    

      

        
Automatisch gefundene Zusammenhänge

        

          
Jede Kennzahl wird mit ihrem eigenen 28-Tage-Mittel verglichen; getestet wird, ob die Abweichungen zusammen schwanken, mit Zeitversatz (Training am Montag gegen die Nacht auf Dienstag). Belastbar heißt: hält der Korrektur für viele gleichzeitige Tests stand. Tendenz heißt: nur ohne diese Korrektur auffällig. Ein fester Wochenplan oder eine Krankheitswoche kann trotzdem Scheinzusammenhänge erzeugen.

          
Quelle: data/insights.json · python -m healthsync analyze · Spearman-Korrelation, Effekt als Theil-Sen-Steigung, Benjamini-Hochberg-Korrektur · Methode: docs/analysis.md

        

        

          
          

        

        

      

      

        
Trainingslast und HRV der Folgenacht

        

          
Jeder Punkt ist ein Tag. Waagrecht die Summe der Garmin-Trainingslast aller Aktivitäten, Ruhetage mit 0. Senkrecht die HRV der folgenden Nacht im Vergleich zum 7-Tage-Mittel bis zu diesem Tag. r ist der Korrelationskoeffizient; er zeigt einen Zusammenhang, keine Ursache.

        

        

      

      

        
Tonnage und HRV der Folgenacht

        

          
Jeder Punkt ist ein Krafttrainingstag: waagrecht die Tonnage aller Arbeitssätze, senkrecht die HRV der folgenden Nacht im Vergleich zum 7-Tage-Mittel bis zum Trainingstag.

        

        

      

      

        
Schlaf der Vornacht und Tagesform

        

          
Jeder Punkt ist eine Krafteinheit: waagrecht der Sleep Score der Nacht davor, senkrecht das e1RM der Einheit im Vergleich zum besten Wert der 28 Tage davor, gemittelt über die Hauptübungen.

So wird gerechnet
Begriffe und Berechnungen auf dieser Seite

        

          
7-Tage-Mittel
Mittelwert aller vorhandenen Werte der letzten 7 Kalendertage einschließlich des Tages selbst. Tage ohne Messung zählen nicht mit.

          
Zeitversatz
Garmin-Werte eines Datums gehören zur Nacht davor. Training am Montag wirkt also auf die Werte vom Dienstag.

          
HRV
Herzfrequenzvariabilität im Schlaf in Millisekunden. Der Normalbereich ist Garmins persönliche Spanne aus den letzten Wochen.

          
Training Readiness, Body Battery
Garmins Zusammenfassungen aus Schlaf, HRV, Stress und Belastung, jeweils 0 bis 100.

          
Arbeitssatz, Tonnage
Arbeitssätze sind alle Sätze außer Aufwärmsätzen. Tonnage ist die Summe aus Gewicht × Wiederholungen dieser Sätze.

          
Geschätztes 1RM (e1RM)
Epley: Last × (1 + Wiederholungen / 30). Pro Einheit zählt der beste Arbeitssatz mit bis zu 10 Wiederholungen. Beim Klimmzug ist die Last Körpergewicht plus Zusatzgewicht.

          
Relative Kraft
Geschätztes 1RM geteilt durch das 7-Tage-Mittel des Körpergewichts am Tag der Einheit.

          
Trainingslast
Garmins Wert pro Aktivität aus dem geschätzten Sauerstoffdefizit (EPOC), pro Tag summiert. Er macht Bouldern, Bergtouren und Radfahren vergleichbar.

          
Schlafmitte, sozialer Jetlag
Die Schlafmitte liegt zwischen Einschlafen und Aufwachen. Ihre Verschiebung am Wochenende gegenüber Werktagen heißt sozialer Jetlag.

          
r und ρ
Korrelationskoeffizienten von −1 bis 1. Sie zeigen, wie eng zwei Werte gemeinsam schwanken, nicht ob einer den anderen verursacht. Unter etwa 20 bis 30 Punkten schwanken sie stark.

Als App installieren

      

        
          
iPhone, iPadIn Safari Teilen → „Zum Home-Bildschirm“. Die App hat dort eigenen Speicher: verbinde sie nach dem Installieren einmal mit GitHub.

          
AndroidIn Chrome Menü ⋮ → „App installieren“ oder das Symbol  oben in der Leiste.

          
Mac, PCIn Chrome oder Edge das Installieren-Symbol in der Adressleiste oder das Symbol oben; in Safari auf dem Mac Ablage → „Zum Dock hinzufügen“.

        
      

      
Installieren geht nur über die GitHub Page oder einen lokalen Server, nicht in einer eingebetteten Vorschau. Die App lädt beim Öffnen und beim Zurückkehren nach mehr als 15 Minuten neu; dazwischen über  oder die Taste R. Ohne Verbindung zeigt sie den zuletzt geladenen Stand, wenn der Token auf dem Gerät gespeichert ist.

    

    

      
Bereiche

      
Deine eigenen Daten zeigt die Seite, wenn sie im Repo über einen lokalen Server läuft oder mit deinem privaten Daten-Repository verbunden ist (Daten → Datenquellen). Jeder Bereich lässt sich über „Einklappen“ schließen; die Kernaussage bleibt sichtbar. Diese Einstellung und der Zeitraum werden in diesem Browser gespeichert. Das ? an einer Karte erklärt, was sie zeigt und woher die Daten kommen. Berechnungen und Begriffe stehen unter Daten → So wird gerechnet.

    

  




  

    

      
Mit GitHub verbinden

      
    

    
Die Seite liest deine CSV-Dateien direkt aus deinem privaten Daten-Repository. Dafür braucht sie einen Token, der nur dieses eine Repository lesen darf.

    

      
      
    

    

      
      
    

    
    

    

    

      So erstellst du den Token
      
    
        
  1. Auf GitHub einen neuen Fine-grained Token anlegen. Der Weg dorthin: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. 
        
  2. Token name zum Beispiel „healthsync dashboard“, Expiration nach Wunsch, etwa ein Jahr.
    3. 
        
  3. Repository access: Only select repositories und nur dein Daten-Repository auswählen.
    4. 
        
  4. Permissions → Repository permissions → Contents: Read-only. Mehr braucht die Seite nicht; „Metadata: Read-only“ setzt GitHub automatisch dazu.
    5. 
        
  5. Auf Generate token klicken, den Token kopieren und hier einfügen.
    6. 
      

      
Der Token geht nur an api.github.com und bleibt in diesem Browser. Er kann nichts ändern und keine anderen Repositories lesen.
